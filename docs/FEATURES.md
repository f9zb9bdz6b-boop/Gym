# Features Checklist

- **Personal Profile & Onboarding**: Profile setup, historical `bodyMetrics`, automatic target calculation.
- **Workout Planner & Live Logger**: PPL, Upper/Lower, Full Body, Bro Split templates; 12-muscle-group Exercise Library; Live set logging with auto-save, rest timer, previous-best comparison, and PR detection.
- **Nutrition & Calculators**: 6-meal Food Tracker, Indian & global food database with `verified`/`estimated`/`user_entered` labels, 11 calculators (Mifflin-St Jeor BMR, TDEE, macros, BMI, hydration, weight progression).
- **Goals, Activity & Recovery**: Daily checklist, custom habits, activity expenditure logger, sleep & readiness tracking.
- **Progress & Analytics**: Recharts visualizations for weight, volume, and nutrition with date-range filters.
- **AI Assistant**: Offline deterministic engine with meal parsing & confirmation flow.
- **Backup & Restore**: Full JSON export, Zod schema validation, and restore.
